# SAVEUR Booking

Тестовое задание на позицию Trainee Frontend Developer: адаптивная страница онлайн-бронирования столика с валидацией, имитацией отправки и экраном подтверждения.

## Стек

- Next.js 16 (App Router)
- React 19
- TypeScript
- CSS Modules
- Vitest

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Дополнительные команды:

```bash
npm run build  # production-сборка
npm run lint   # проверка ESLint
npm test       # unit-тесты валидации телефона
```

## Принятые решения

Форма и экран подтверждения разделены на самостоятельные компоненты, а типы и функции валидации вынесены в отдельные файлы. Валидация запускается при потере фокуса и перед отправкой; отправка имитируется таймером в 1,5 секунды с блокировкой формы и индикатором загрузки. Интерфейс построен без UI-библиотек, чтобы сохранить небольшое количество зависимостей и показать базовые навыки React и CSS.
